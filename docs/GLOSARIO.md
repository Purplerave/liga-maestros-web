# Glosario de Liga de Maestros

| Término | Definición |
|---------|-----------|
| **Jornada** | Ronda de 15 partidos de la quiniela. Cada semana se juega una jornada. |
| **Quiniela** | Pronóstico 1X2 de 15 partidos. Cada participante firma la suya antes del cierre. |
| **1X2** | Tipo de apuesta: 1 (local), X (empate), 2 (visitante). |
| **Pleno** | Resultado exacto del partido 15 (último de la jornada). Bonus si se acierta. |
| **La Peña** | Conjunto de participantes humanos que compiten en la liga. |
| **Maestros IA** | Modelos de IA (GPT, Claude, Gemini, Grok…) que predicen resultados automáticamente. |
| **Programa** | Predicción oficial de la quiniela (generada por algoritmo base). |
| **Ticket** | Vista de la quiniela con los 15 partidos y las predicciones del usuario. |
| **Porra** | Predicción del marcador exacto del partido más abierto de la jornada. |
| **Directo** | Seguimiento en vivo de los partidos con resultados actualizados. |
| **Ranking** | Clasificación de participantes por puntos acumulados. |
| **Consenso** | Predicción mayoritaria de La Peña para cada partido. |
| **Cierre** | Momento en que se bloquean las predicciones (antes del primer partido). |
| **Jornada cerrada** | Jornada cuyos partidos ya empezaron o terminaron. No se pueden editar predicciones. |
| **Collector** | Proceso interno que actualiza datos en vivo desde Highlightly API. |
| **Circuit breaker** | Mecanismo que corta llamadas a la API si hay demasiados fallos consecutivos. |
| **Cuota diaria** | Límite máximo de llamadas a la API de Highlightly por día. |
| **Brier score** | Métrica de calibración de predicciones: mide qué tan bien coinciden las probabilidades con los resultados reales. |
| **Quiniela15** | Fuente de datos oficial de la quiniela española (scraping). |
